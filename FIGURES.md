# Figure provenance

Every listed figure is generated by a committed Python script. Outputs stay
local. To reproduce from cloud data, run Part A first, then Part B, using their
documented dependencies. No manually redrawn figures are required.

| Figure filename | Generating script |
|---|---|

| `kassala_return_levels.png` | `part_a_extremes/analyze.py` |

Part B calls `plot_results.py` for the final versions of both town figures and
the combined comparison. It can also redraw them directly from the saved
`daily_member_counts.csv`, with no cloud access.

Part B writes `run_metadata.json` with the script SHA-256, Git commit revision,
forecast initialization, QC corrections, and domain-check status. The cached
run's source-domain validation limitation must be retained if its figures are
presented before refreshing metadata checks online. This repository does not
contain a slide deck; this list covers the figures produced by Parts A and B.

Task C's `part_c_forecast_signals/analyze.py` generates `*_heatmap.png` and
`*_strongest_start_plume.png` for the five town names (lowercase, spaces replaced
with underscores). Its run metadata records the generating script hash and Git
revision. These figures are pending the first connected Task C data extraction.

Task D's `part_d_risk_maps/analyze.py` generates four
`probabilities_YYYY-MM-DD.png` figures and `sampled_season_frequency.png` with
town markers. The default frequency summarizes 20 sampled forecast intervals,
not the full season. Its metadata records the script hash and Git revision.

The revised Task A is saved as `task_A`. Its `analyze.py` generates five
`*_return_levels.png` figures and `regional_10yr_24hr.png`, using retained real
CMORPH inputs. Its metadata records script/configuration/input hashes and the
Git revision. `results.md` includes explicit observed-versus-fit diagnostics.

The revised Task B is saved as `task_B`. Its `analyze.py` recomputes daily
rainfall, three-threshold counts and xclim heavy days from retained cumulative
forecasts, and calls its committed `plot_results.py` to generate both town
figures and `two_town_threshold_comparison.png`. Current analysis/renderer and
input hashes plus Git revision are recorded with its final outputs. Task B now
uses all five towns from grid.json; its combined figure is
`task_B/five_town_threshold_comparison.png` (five rows, three thresholds).
