# task_A: observed rainfall extremes

Final Task A outputs are saved alongside this script. The five towns are
Khartoum, Kassala, Gedaref, El Obeid and Nyala. Each has 27 annual CMORPH
maxima (1998–2024) at **24 h and 6 h**. This implementation follows workshop
`04_cmorph_return_periods.py`, using the actual previously extracted data.

Run from the repository:

```sh
../part_a_extremes/.venv312/bin/python -u task_A/analyze.py
```

There are no cloud downloads. The three source files are retained locally in
`inputs/`: `annual_maxima.csv`, `thresholds.csv`, `regional_10yr_24hr.nc`.
To re-extract them from the public store, run the committed original
`part_a_extremes/analyze.py`, then copy these three files into `task_A/inputs/`.
Alternatively pass `--inputs part_a_extremes` to use that extraction directly.
The standalone dependencies are listed in `requirements.txt`.

## Open these outputs

- **`results.md`**: full numerical interpretation, named upper-tail departure
  years, all threshold crossing years, and largest-year-removal extension.
- Five **`*_return_levels.png`** files: annual maxima and return-level comparison,
  with separate rows for 24 h and 6 h.
- **`regional_10yr_24hr.png`**: regional 10-year 24 h level, with five town markers.
- **`thresholds_short.csv`**: compact 2-, 10- and 50-year depths table.
- `thresholds.csv`: reusable depths, coordinates, units, counts and exceedance years.
- `annual_maxima.csv`: all 270 observations.
- `observed_vs_fit_summary.csv` and `fit_diagnostics.csv`: named departures and
  full observed-versus-published comparisons at Weibull plotting positions.
- `sensitivity.csv`: 50-year MLE levels with and without the largest year.
- `gumbel_parameters.csv`: implied published curve and independent MLE parameters.
- `regional_10yr_24hr.nc`: actual map values.
- `run_metadata.json`: script, configuration and input hashes, Git revision,
  source information and recorded checks.

Rainfall depths are **mm accumulated over the stated duration**, not hourly
rates. The published Gumbel curve is reconstructed from its three return levels
and checked for consistency. MLE is a separate refit; the sensitivity comparison
uses MLE for both samples. A descriptive upper-tail departure does not establish
that an observation is an outlier or that the statistical fit has failed.
The 50-year level extrapolates beyond 27 observed years.

The cached regional map is checked for ascending latitude, town coverage and
agreement with the five 10-year threshold values. Earlier source-domain
verification, when available from Task C metadata, is recorded explicitly as
historical evidence rather than a fresh cloud check.

All figures are generated by this committed script; data and figures stay local.
